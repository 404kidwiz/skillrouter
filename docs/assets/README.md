# Skillrouter hero asset

`skillrouter-hero.png` is a static 1672 × 941 PNG generated for this repository on 2026-10-24 with the built-in image generation tool. It is illustrative artwork, not a screenshot, benchmark, or representation of a physical product. No third-party logos or source images were supplied.

Concept: a jade-green skill dispenser holds a large library of cards behind glass and delivers three selected cards into a small notebook-shaped tray. The pale-apricot background and tactile illustration make selective retrieval approachable. The user selected this variation on 2026-10-24. Static artwork needs no motion or playback; the README also includes alt text and a text/Mermaid explanation.

## Use and maintenance

The image lives in `docs/assets` so the repository and npm distribution both carry the README asset. Keep the title and metaphor legible when changing it. Preserve this prompt/provenance and inspect the rendered README at narrow and desktop widths after replacement. The README's product claims belong in selectable text; the artwork should not be the only explanation.
